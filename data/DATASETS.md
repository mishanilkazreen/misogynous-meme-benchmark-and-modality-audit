# Dataset Setup Guide

This directory contains datasets for training and evaluating the content moderation models.

## Dataset Requirements

According to Requirements 1.1-1.3:

- **Minimum size**: 5,000 annotated images
- **Content types**: 
  - High visibility + textual
  - High visibility + symbolic
  - Low visibility + textual
  - Low visibility + symbolic
- **Annotation quality**: Fleiss Kappa ≥ 0.783

## Recommended Datasets

### Option 1: HatefulMemes Dataset (Facebook AI)
- **Source**: [https://ai.facebook.com/tools/hatefulmemes/](https://ai.facebook.com/tools/hatefulmemes/)
- **Size**: 10,000+ images with multimodal annotations
- **Format**: JSON annotations with image-level labels
- **License**: CC BY-NC 4.0

### Option 2: MMHS150K (Multimodal Hate Speech)
- **Source**: [https://github.com/gombru/hate-speech-dataset](https://github.com/gombru/hate-speech-dataset)
- **Size**: 150,000 tweets with images
- **Format**: Image + text pairs with hate speech labels

### Option 3: Custom Dataset
If using your own dataset, ensure it meets the requirements above.

## Setup Instructions

### Step 1: Create Directory Structure

```bash
cd data
mkdir -p raw/{train,val,test}
mkdir -p annotations/yolo/{train,val,test}
mkdir -p annotations/vlm
mkdir -p processed/{blur_equalized,augmented}
```

### Step 2: Download Dataset

**Example: HatefulMemes Dataset**

```bash
# Download from Facebook AI (requires registration)
# Visit: https://ai.facebook.com/tools/hatefulmemes/

# After downloading, extract to data/raw/
unzip hateful_memes.zip -d raw/

# The dataset comes with a JSON file containing annotations
# You'll need to convert these to YOLO format for object detection
```

### Step 3: Organize Images

```bash
# Split images into train/val/test (70/15/15 split)
# Example Python script:

python << 'EOF'
import os
import shutil
from pathlib import Path
import random

# Set seed for reproducibility
random.seed(42)

# Get all images
images = list(Path('raw/img').glob('*.png'))
random.shuffle(images)

# Calculate splits
total = len(images)
train_size = int(0.7 * total)
val_size = int(0.15 * total)

# Split
train_imgs = images[:train_size]
val_imgs = images[train_size:train_size + val_size]
test_imgs = images[train_size + val_size:]

# Move to respective directories
for img in train_imgs:
    shutil.copy(img, 'raw/train/')
for img in val_imgs:
    shutil.copy(img, 'raw/val/')
for img in test_imgs:
    shutil.copy(img, 'raw/test/')

print(f"Split complete: {len(train_imgs)} train, {len(val_imgs)} val, {len(test_imgs)} test")
EOF
```

### Step 4: Prepare Annotations

#### YOLO Format (for object detection)

Each image needs a corresponding `.txt` file with bounding boxes:

**Format**: `<class_id> <x_center> <y_center> <width> <height>`
- All values normalized to [0, 1]
- `x_center`, `y_center`: center of bounding box
- `width`, `height`: box dimensions

**Example**: `annotations/yolo/train/image_001.txt`
```
0 0.5 0.3 0.2 0.15
1 0.7 0.6 0.1 0.1
```

Classes:
- `0`: Textual hate content
- `1`: Symbolic hate content

#### VLM Format (for image-level classification)

Create JSON files with image-level labels:

**Example**: `annotations/vlm/train.json`
```json
[
  {
    "image_id": "image_001.jpg",
    "image_path": "raw/train/image_001.jpg",
    "has_hateful_content": true,
    "message_type": "textual",
    "visibility_level": "low",
    "extracted_text": "",
    "annotator_agreement": 0.85
  },
  {
    "image_id": "image_002.jpg",
    "image_path": "raw/train/image_002.jpg",
    "has_hateful_content": true,
    "message_type": "symbolic",
    "visibility_level": "high",
    "extracted_text": "",
    "annotator_agreement": 0.92
  }
]
```

### Step 5: Validate Dataset

After organizing your data, validate it:

```python
from utils.dataset import DatasetManager

# This will be implemented in task 2.1
manager = DatasetManager()
dataset = manager.load_dataset('data/raw/train')
kappa = manager.validate_annotations('data/annotations/vlm/train.json')

print(f"Dataset size: {len(dataset)}")
print(f"Fleiss Kappa: {kappa:.3f}")
assert kappa >= 0.783, "Annotation quality below threshold"
```

## Important Notes

⚠️ **Ethical Considerations**:
- Ensure proper licensing for hate content datasets
- Follow data privacy and security guidelines
- Handle sensitive content responsibly
- Consider psychological impact on annotators

⚠️ **Data Privacy**:
- Raw data files are excluded from version control (see `.gitignore`)
- Never commit actual hate content images to public repositories
- Use secure storage for sensitive datasets

⚠️ **Quality Control**:
- Verify Fleiss Kappa ≥ 0.783 before training
- Ensure balanced distribution across all 4 content types
- Review edge cases and ambiguous examples
