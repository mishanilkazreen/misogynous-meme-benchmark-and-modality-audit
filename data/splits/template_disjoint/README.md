# Template-disjoint MAMI split (EXP-02)

Generated by `scripts/revision/template_overlap.py` (run
`uv run --with imagehash==4.3.2 python -m scripts.revision.template_overlap all`); do not edit by hand.

## Columns

The MAMI TSV columns (`file_name`, `label`, `shaming`, `stereotype`, `objectification`, `violence`,
`text`, copied verbatim from the Kaggle TSVs) plus:

- `template_id`: meme-template cluster (`T` + cluster number).
- `source_split`: original MAMI split of the meme (`train`, `validation` or `test`). It selects the image
  folder in the Kaggle cache: `training_images/` for train/validation, `test_images/` for test.

## Construction

1. A 64-bit pHash (`imagehash.phash`) of every image and the committed CLIP ViT-L-14 image embeddings
   (`results/embeddings/*_vit_l_14_quickgelu_ocr_paddleocr.npz`) of all 11,000 memes.
2. Two memes share a template when pHash Hamming distance <= 5 or CLIP cosine >= 0.907 (the
   "central" setting in `results/revision/exp02/overlap.json`, chosen so that the estimated number of
   chance matches per meme is at most 0.03). Templates are connected components of that graph.
3. Templates are visited in random order (seed 20260517). Templates with 2-25 memes go to a split
   drawn in proportion to its remaining capacity, subject to label capacity; larger templates go to
   train. Single-meme templates then fill validation and test exactly.

Result: train/validation/test = 9000/1000/1000 memes, 50% misogynous in each, and no `template_id`
shared between any two splits. Validation and test draw about 82% of their memes from the original
train split, so they are not the original MAMI validation/test sets. Within validation and test,
image ids are unique; train contains a few file names that also occur in the original test folder
(different images, disambiguated by `source_split`).

## Use

```bash
export MAMI_SPLIT_DIR=data/splits/template_disjoint
export MAMI_SPLIT_TAG=tdisjoint
```

`utils/dataset.py` then reads these TSVs, and `scripts/train_vlm.py` / `scripts/benchmark_qwen2vl.py`
append `_tdisjoint` to adapter directories and output files (see `sciama/JOBS.md` S4).
