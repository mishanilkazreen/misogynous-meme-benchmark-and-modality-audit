# results/validation/

Benchmark metrics computed on the **validation split** of the MAMI dataset.

These files are generated by the evaluation scripts during model development and
hyperparameter tuning. They are **not** final reported results.

## File naming convention

```
<model>_validation[_<variant>].json
```

| Segment | Meaning |
|---------|---------|
| `model` | `clip`, `llava`, `qwen2vl`, `visualbert`, `xgboost`, `gemini`, … |
| `validation` | always `validation` for this directory |
| `variant` | optional: model size, LoRA checkpoint name, or task type (`multiclass`, `finetuned`, …) |

## Notes

- Results here may be superseded by improved checkpoints.
- For **final reported numbers**, see [`../test/`](../test/README.md).
