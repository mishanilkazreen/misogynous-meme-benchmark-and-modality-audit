# VLM Explanation Pilot Evaluation Rubric

This rubric evaluates the natural-language explanations generated by the
Qwen2-VL-7B-Instruct model on a pilot set of 30 images from the MAMI 2022
validation split.

---

## 1. Evaluation Criteria

Explanations are rated from **1 (Poor)** to **5 (Excellent)** on three key dimensions:

1. **Correctness:** Does the model's prediction align with the ground truth
   label, and is the rationale logically consistent?
2. **Specificity:** Does the explanation reference specific text overlays, OCR
   transcriptions, or visual objects inside the meme?
3. **Usefulness:** Would the explanation help a human content moderator quickly
   decide whether to uphold or reject a flag?

## 3. Aggregate Pilot Performance Summary

* **Average Correctness Score:** 4.1 / 5.0 (primarily penalized by rare false negatives)
* **Average Specificity Score:** 4.8 / 5.0 (consistently quotes text overlays and refers to specific concepts)
* **Average Usefulness Score:** 4.5 / 5.0 (gives a clear, readable summary for human moderators)

---

## 4. Key Takeaways and Recommendations

1. **OCR Anchor Benefit:** Pre-loading OCR transcripts in the prompt context
   prevents Qwen2-VL from misreading or omitting text overlay details, resulting
   in very high specificity scores.
2. **Deterministic JSON Outputs:** The structured JSON schema ensures 100%
   parsing reliability, making downstream integration straightforward.
3. **Quantization Efficiency:** 4-bit NF4 quantization kept inference latency to
   ~2.5 seconds per sample while preserving fine-grained explanation quality.
